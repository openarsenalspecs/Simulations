# The Uncertain Machine

**Don’t Memorize Reality. Interact With It.**

The Uncertain Machine is an open-source, AI-powered scientific simulation platform where players of all ages explore physics, biology, chemistry, and complex systems through experimentation, curiosity, and play.

Instead of memorizing facts, users discover how reality behaves by interacting with it directly.

---

# 🌌 Core Vision

A living, evolving educational world where:
- Science is learned through experimentation, not memorization
- AI adapts explanations to every level of understanding
- Simulations are interactive, reversible, and replayable
- Curiosity drives progression, not curriculum structure
- Every discovery becomes a personal artifact of learning

---

# 🎮 Full Feature List

## 🧠 Core Learning System
- Curiosity-driven gameplay (no quizzes, no grading)
- Infinite depth scaling from early learners to expert researchers
- Real-time scientific simulation environments
- Multi-domain support: physics, biology, chemistry, astronomy, systems theory

---

## 🤖 AI-Driven Teaching System
- Dynamic AI-generated scientific guides and characters
- Humor-driven educational personalities generated on demand
- Adaptive explanation depth (beginner → expert seamlessly)
- Concept-aware teaching using a structured knowledge graph
- Misconception-aware clarification system

---

## 📚 Living Knowledge Graph
- Science represented as interconnected concept nodes
- Versioned scientific models (multiple theories can coexist)
- Confidence scoring and provenance tracking for concepts
- Continuous expansion through verified online “Science Packs”
- Historical evolution of scientific understanding preserved

---

## 🌐 Online Science Sync System (AGPL-Controlled)
- Secure, signed “Science Pack” updates
- Continuous scientific model improvements
- Modular updates (concepts, simulations, characters, media)
- Transparent version registry and rollback support
- Community-reviewed scientific contributions

---

## 📸 Curiosity Capture System
- Instant screenshot capture of any simulation moment
- Full context stored (variables, state, concepts, timestamps)
- Replayable experimental snapshots
- Annotation tools (draw, text, voice notes)
- Personal discovery library for each player

---

## 🎞️ Replay & Simulation Review System
- Full experiment replay generation
- Time-based variable visualization
- Multi-layer replay explanations:
  - Narrative layer
  - Scientific layer
  - Data-driven analytical layer
- Side-by-side comparison of different outcomes

---

## 📤 Export System
- PNG/JPG exports (clean or annotated)
- MP4/WebM simulation replays
- Auto-generated lab reports (PDF/Markdown)
- `.curio` reproducible experiment files
- JSON-based experiment state exports for developers

---

## 🔤 Caption-First Accessibility System
- Built-in real-time closed captioning from knowledge graph (not speech-to-text)
- Multi-depth caption modes:
  - Beginner (intuitive explanation)
  - Standard (narrative clarity)
  - Advanced (technical/scientific detail)
- Clickable caption words for definitions and mini-simulations
- Read-along highlighting for early literacy support
- Dyslexia-friendly and accessibility-first UI design

---

## 🎮 Simulation Engine
- Deterministic, reproducible scientific simulations
- Physics-based modeling (gravity, motion, energy systems)
- Biological and chemical system simulation frameworks
- WebAssembly acceleration for performance-critical systems
- Variable manipulation with immediate feedback loops

---

## 🧪 Scientific Modularity
- Plug-in based science domains (physics, biology, chemistry, etc.)
- Expandable simulation packs
- Coexisting scientific models (classical vs modern frameworks)
- Experimental sandbox mode for custom systems

---

## ⚙️ Technical Architecture
- Built on Godot Engine for cross-platform deployment
- Python-based scientific computation (NumPy, SciPy)
- WebAssembly modules for high-performance simulation
- Rust/Go backend sync system for secure updates
- Graph-based knowledge representation (JSON-LD style structure)
- Deterministic seed-based simulation replay system

---

## 🔐 Security & Integrity
- Cryptographically signed Science Pack updates
- Transparent version tracking of all scientific models
- Verified update pipeline for educational integrity
- Reproducible simulations for auditability

---

## 🌍 Open Source & Community
- Fully open-source under AGPL-3.0+
- Community-driven scientific module contributions
- Educator-friendly expansion system
- Transparent governance for knowledge updates
- Designed for classrooms, research labs, and independent learners

Players are not students.
